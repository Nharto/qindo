# P2P Tukar Cash

Halaman sederhana untuk tukar cash dan crypto secara peer to peer.

## Fitur
- Tukar cash: bayar via QRIS, terima uang tunai (Rp5.000 sampai Rp50.000)
- Tukar crypto: XMR, DCR, FIRO, ZANO, USDT (TRC20 dan BEP20)
- Kurs live dengan beberapa sumber cadangan
- Grafik harga 24 jam, 7 hari, dan 30 hari
- Tampilan mengikuti mode gelap dan terang

## Cara kerja
1. Pilih nominal (Cash) atau coin (Crypto).
2. Bayar via QRIS, atau kirim ke alamat yang tampil.
3. Tunjukkan bukti bayar atau TXID, lalu terima uangmu.

Biaya admin 5% dari nominal.
